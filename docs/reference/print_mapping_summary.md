# Print Mapping Summary

Display detailed summary of column mappings

## Usage

``` r
print_mapping_summary(mapping_result)
```

## Arguments

- mapping_result:

  Result from map_user_columns()

## Value

Invisibly returns a summary data frame

## Examples

``` r
if (FALSE) { # \dontrun{
mapping <- map_user_columns(my_data, config)
print_mapping_summary(mapping)
} # }
```
