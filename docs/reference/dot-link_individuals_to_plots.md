# Link Individuals to Plots (Internal)

Gets plot IDs (id_liste_plots) for each individual.

## Usage

``` r
.link_individuals_to_plots(individuals_data, con, progress = TRUE)
```

## Arguments

- individuals_data:

  Data frame with plot_name column

- con:

  Database connection

- progress:

  Show progress

## Value

Data frame with id_liste_plots added
