# JavaScript returning every mode card to its unchosen look

The counterpart of \`.mode_selection_js()\`: no card selected, none
dimmed, and no scrolling, since a reset happens while another step is on
screen.

## Usage

``` r
.mode_clear_js(card_ids)
```

## Arguments

- card_ids:

  Character vector of namespaced card element ids.

## Value

A single string of JavaScript.
