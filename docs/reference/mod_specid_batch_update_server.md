# Batch update server

Batch update server

## Usage

``` r
mod_specid_batch_update_server(id, validated_data, mappings, pool_main, i18n)
```

## Arguments

- id:

  Module id

- validated_data:

  Reactive validated rows

- mappings:

  Reactive mappings list

- pool_main:

  Reactive main DB pool

- i18n:

  Reactive translator
