# Process trimble data

Process raw trimble data and provide individuals data ready to import
and log file with potential problems

## Usage

``` r
process_trimble_data(PATH = NULL, plot_name = NULL, format = "dbf")
```

## Arguments

- PATH:

  string path to trimble data

- plot_name:

  string plot name to give to plot

## Value

A list with two tibbles
