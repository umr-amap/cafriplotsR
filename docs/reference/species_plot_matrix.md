# Get species-plot data frame

Convert the extract of database into a species-plot data frame

## Usage

``` r
species_plot_matrix(data_tb, tax_col = "tax_sp_level", plot_col = "plot_name")
```

## Value

A data frame with taxa as row, plot as columns and values as number of
individuals
