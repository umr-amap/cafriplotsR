# Query in taxa trait table

Query in taxa trait table by id or pattern

## Usage

``` r
query_trait(id_trait = NULL, pattern = NULL, con = NULL)
```

## Arguments

- id_trait:

  integer id of trait to select

- pattern:

  string vector trait to look for in the table

## Value

tibble with query results
