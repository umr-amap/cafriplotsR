# Compare two row-tibbles and generate HTML with differences

Compare two row-tibbles and generate HTML with differences

## Usage

``` r
.comp_print_vec(vec_1, vec_2)
```

## Arguments

- vec_1:

  A tibble with one row

- vec_2:

  A tibble with one row

## Value

A list: (1) tibble of differing columns, (2) HTML table highlighting
differences
