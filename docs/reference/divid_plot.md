# Divid into quadrats a 1ha plot

Divid into quadrats a 1ha plot

## Usage

``` r
divid_plot(corners)
```

## Arguments

- corners:

  sf POINT the outputs WGS 84 of extract_corners function

- plot_name:

  vector string the name of the plot

## Value

list sub_plot element is sf POLYGON with each quadrat as polygon
