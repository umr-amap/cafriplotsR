# Print a database activity summary to the console

Formats and prints the output of
[`get_db_activity`](https://umr-amap.github.io/cafriplotsR/reference/get_db_activity.md)
using cli for readable, colour-highlighted output.

## Usage

``` r
# S3 method for class 'db_activity'
print(x, ...)
```

## Arguments

- x:

  A `db_activity` object from
  [`get_db_activity`](https://umr-amap.github.io/cafriplotsR/reference/get_db_activity.md).

- ...:

  Ignored.

## Value

`x` invisibly.
