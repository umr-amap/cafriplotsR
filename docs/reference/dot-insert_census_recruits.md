# Insert recruits into \`data_individuals\`

Insert recruits into \`data_individuals\`

## Usage

``` r
.insert_census_recruits(recruits, con)
```

## Arguments

- recruits:

  Data frame with \`id_table_liste_plots_n\`, \`tag\` and any of the
  optional individual columns.

- con:

  Database connection.

## Value

Data frame with \`id_individuals\`, \`tag\` and \`plot_name\`.
