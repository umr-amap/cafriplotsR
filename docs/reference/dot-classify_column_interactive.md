# Classify Column Interactively - Internal

Asks user whether a column represents a feature/trait measurement.

## Usage

``` r
.classify_column_interactive(column_name, sample_values)
```

## Arguments

- column_name:

  Name of the column to classify

- sample_values:

  Sample values from the column (for user reference)

## Value

Character: "yes", "no", or "skip"
