# Display multiple changes grouped by column

Display multiple changes grouped by column

## Usage

``` r
.display_changes_grouped(changes_df, id_column, max_display = 10)
```

## Arguments

- changes_df:

  Dataframe with columns: id_column_value, column, old_value, new_value

- id_column:

  Name of ID column

- max_display:

  Maximum number of changes to display per column
