# Mapping from flag1_rainfor codes to mortality_risk_flag tokens

Derived from
[`.default_observation_flags()`](https://umr-amap.github.io/cafriplotsR/reference/dot-default_observation_flags.md)
in `openforis_processing.R`, inverted so single-letter codes map to
standardized tokens. Codes not in this table are kept as unresolved.

## Usage

``` r
.flag1_to_mortality_map()
```
