# Add new plot metadata

Add metadata for new plots

## Usage

``` r
add_plots(new_data, col_names_select, col_names_corresp)
```

## Arguments

- new_data:

  tibble

- col_names_select:

  string a vector of string indicating columns names of new_data

- col_names_corresp:

  string a vector of string indicating to which columns selected columns
  of new_data corresponds

## Value

No return value, new plots are added
