# Execute feature import (internal)

Execute feature import (internal)

## Usage

``` r
.execute_feature_import(data, config, con, dry_run = TRUE, i18n = NULL)
```

## Arguments

- data:

  Data frame of features to import

- config:

  Feature configuration list

- con:

  Database connection

- dry_run:

  Logical, if TRUE only simulate

- i18n:

  Translator object

## Value

List with import results
