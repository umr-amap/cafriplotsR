# Review Mappings Interactively (Internal Helper)

Allow user to review and adjust automatic mappings

## Usage

``` r
.review_mappings_interactive(result, user_data, schema_cols, config)
```

## Arguments

- result:

  Mapping result from map_user_columns

- user_data:

  User data

- schema_cols:

  Valid database columns

- config:

  Import configuration

## Value

Updated mapping result
