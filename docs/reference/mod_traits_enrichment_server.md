# Traits Enrichment Module - Server

Traits Enrichment Module - Server

## Usage

``` r
mod_traits_enrichment_server(id, results, column_name, i18n)
```

## Arguments

- id:

  Character, module ID

- results:

  Reactive list from review module (contains final matched data)

- column_name:

  Reactive returning the selected column name containing taxa

- i18n:

  Reactive returning shiny.i18n translator
