# Prepare Individuals Data for Insert (Internal)

Prepares data frame for insertion into data_individuals table. Selects
and orders columns appropriately.

## Usage

``` r
.prepare_individuals_data(individuals_data, progress = TRUE)
```

## Arguments

- individuals_data:

  Data frame with individual data and id_liste_plots

- progress:

  Show progress

## Value

Data frame ready for insert
