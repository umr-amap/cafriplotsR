# Guess the trait-name and value columns of a long-format table

Guess the trait-name and value columns of a long-format table

## Usage

``` r
.guess_long_trait_columns(cols)
```

## Arguments

- cols:

  Column names of the uploaded table.

## Value

List with \`name\`, \`value_num\` and \`value_char\`, each a column name
or \`""\`.
