# Build Hierarchy Tree HTML

Creates the nested tree view HTML structure.

## Usage

``` r
build_hierarchy_tree_html(hierarchy, current_id, i18n)
```

## Arguments

- hierarchy:

  Hierarchy list from get_taxon_hierarchy

- current_id:

  The ID of the currently selected taxon

- i18n:

  i18n translator

## Value

Shiny tagList
