# Display a single change with visual comparison

Display a single change with visual comparison

## Usage

``` r
.display_change(
  id,
  column,
  old_value,
  new_value,
  id_column,
  old_genus = NULL,
  old_species = NULL,
  old_family = NULL,
  new_genus = NULL,
  new_species = NULL,
  new_family = NULL
)
```

## Arguments

- id:

  Record ID

- column:

  Column name

- old_value:

  Old value

- new_value:

  New value

- id_column:

  Name of ID column
