# Step 6 Module: Preview Data - Server

Step 6 Module: Preview Data - Server

## Usage

``` r
mod_step6_preview_server(id, validation_result, i18n)
```

## Arguments

- id:

  Module namespace ID

- validation_result:

  Reactive containing validation results

- i18n:

  Reactive returning translator object from shiny.i18n

## Value

Reactive indicating preview confirmed
