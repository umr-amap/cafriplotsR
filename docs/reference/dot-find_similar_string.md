# Internal function

Looking for similar name

## Usage

``` r
.find_similar_string(input, compared_table, column_name)
```

## Arguments

- input:

  string vector of one value containing the string to compare

- compared_table:

  tibble including one column containing the different strings to which
  input should be compared

- column_name:

  string the column name of compared_table containing the compared
  values

## Value

tibble
