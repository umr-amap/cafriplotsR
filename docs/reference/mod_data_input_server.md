# Data Input Module - Server

Data Input Module - Server

## Usage

``` r
mod_data_input_server(id, provided_data = NULL, i18n)
```

## Arguments

- id:

  Character, module ID

- provided_data:

  Reactive or data.frame, optional pre-loaded data

- i18n:

  Reactive returning shiny.i18n translator

## Value

Reactive data.frame with user data
