# Batch lookup server

Batch lookup server

## Usage

``` r
mod_specid_batch_lookup_server(id, data, mappings, pool_main, i18n)
```

## Arguments

- id:

  Module id

- data:

  Reactive uploaded data

- mappings:

  Reactive mappings list

- pool_main:

  Reactive main DB pool

- i18n:

  Reactive translator

## Value

list(matched_data, is_complete)
