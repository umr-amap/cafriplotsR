# Specimen Mapping Module - Server

Specimen Mapping Module - Server

## Usage

``` r
mod_specimen_mapping_server(id, data, con, i18n)
```

## Arguments

- id:

  Module namespace ID

- data:

  Reactive containing uploaded user data

- con:

  Reactive database connection pool

- i18n:

  Reactive returning translator object

## Value

Reactive list containing column mappings
