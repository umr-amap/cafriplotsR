# Census subplot map for the ids picked in the UI

Census subplot map for the ids picked in the UI

## Usage

``` r
.census_selected_map(census_ids, censuses)
```

## Arguments

- census_ids:

  Selected \`id_sub_plots\` values.

- censuses:

  Table from \[.fetch_census_subplots()\].

## Value

Data frame with \`id_table_liste_plots\` and \`id_sub_plots\`.
