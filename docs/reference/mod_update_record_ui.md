# Record update module - UI

Record update module - UI

## Usage

``` r
mod_update_record_ui(id, entity = c("plot", "individual"), i18n)
```

## Arguments

- id:

  Character, module namespace id.

- entity:

  Either \`"plot"\` or \`"individual"\`.

- i18n:

  A \`shiny.i18n\` translator object.

## Value

A Shiny UI element.
