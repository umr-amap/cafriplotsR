# Match Lookup Values (Internal Helper)

Match Lookup Values (Internal Helper)

## Usage

``` r
.match_lookup_values(user_values, db_values, db_ids)
```

## Arguments

- user_values:

  Vector of user-provided values

- db_values:

  Vector of database values

- db_ids:

  Vector of database IDs

## Value

List with exact matches, fuzzy matches, and unmatched values
