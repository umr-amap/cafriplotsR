# Results Export Module - Server

Results Export Module - Server

## Usage

``` r
mod_results_export_server(id, results, original_data, i18n)
```

## Arguments

- id:

  Character, module ID

- results:

  Reactive list from auto matching module

- original_data:

  Reactive data.frame, original user data

- i18n:

  Reactive returning shiny.i18n translator

## Value

NULL (handles download only)
